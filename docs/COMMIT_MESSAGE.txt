## How It Works

### Local Development (No Changes)
```bash

ollama serve
uvicorn app.main:app --reload
```

### Production Deployment
```bash
export LLM_PROVIDER=openai
export OPENAI_API_KEY=sk-proj-your-key-here
# Deploy with Docker, Kubernetes, Lambda, etc.
```
